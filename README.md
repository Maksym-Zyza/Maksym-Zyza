# Hi, I'm Maksym 👋

Frontend engineer from Lviv, Ukraine. I build interfaces for complex products: industrial AI, real-time data and analytics.

I like work where the UI has to make complicated things understandable, whether it is a video stream with synchronized telemetry, a dashboard with heavy data, or a step-by-step flow for training an ML model.

I have 5 years of experience building complex enterprise products: industrial automation (Industry 4.0), business analytics and B2B SaaS platforms for the US market. I build maintainable UI systems, work with real-time data visualization, and connect AI-driven backends with end-user workflows. I take features from the first technical discussion to production.

🌍 Open to remote opportunities
